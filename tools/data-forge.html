✋ Refresh the manual tabs the ✋ tabs above — no API; re-seed from the Looker workbook

What: only the ✋ tabs in the dropdown (the ⚡ tabs auto-refresh on the 10th — leave those). The ✋ tabs are pulled by hand from the sources below into the “Commercial Report Data for Looker” workbook (from the Commercial research guide).
Where each comes from:
  • Vacancy Rate / Offices (per state × asset type: office, retail, industrial) — the 4 commercial agencies: CBRE · Colliers · Savills · Knight Frank (no API).
  • Freight Movement — shipping-container imports, major ports state-by-state (Brisbane, Botany/Sydney, Fremantle, Melbourne, Pilbara Ports [Hedland + Dampier], Darwin, Adelaide, Newcastle) — from each port authority (no single API).
  • National E-Commerce Sales — Statista (subscription).
  • Building Price Indices — ABS Producer Price Indexes → Table 18 (input to house construction, 6 state capitals), series A2390558X.
  • Work From Home — ABS Australia’s Journey to Work.
  • Individuals who accessed a GP — ABS Patient Experiences → Data Cubes, Tables 1–3 (Table 1).
  • % of Pop Accessing Health Services — ABS Patient Experiences (health service use).
  • Fed Gov Health Budget — Federal Budget papers (health portfolio budget statements).
  • Cash Rate / Inflation — RBA cash rate + ABS CPI. (Kept manual — its chart uses an irregular RBA effective-date axis that the monthly Forge series can’t reproduce.)
  • Return on Stocks & Gold / Risk-Reward — dividend-history workbook + stock/gold market data.
Then apply: update the changed tab(s) in the workbook → save it to ~/Downloads/Commercial Report Data for Looker.xlsx → run node scripts/seed-commercial.mjs --write (re-seeds forge_commercial from the workbook) → then run the PUBLISH workflow. PUBLISH’s build-commercial step re-applies the fresh ⚡ API tabs afterward, so re-seeding never clobbers them.
