Text Settings
Data tokens
Type a token into any text box — the live figure is substituted when the slide is drawn, and refreshes itself after each monthly publish. Add a region after a colon ({vac:perth}); leave it off for national. An unknown token stays on screen as typed. Vacancy · {vac:perth} {vac_year:perth} {vac_rank:perth} {vac_rank_of} (rank = tightest first, as "1st"/"4th" — use it instead of writing a superlative that will go stale) Unemployment · {unemp} {unemp_year} Migration · {nom} {nom_peak} {nom_peak_year} {nat_inc} {nat_inc_year} Approvals · {approvals} {approvals_year} {approvals_vs_peak} Rates · {cash_rate} {rate_current} {rate_forecast} {cash_current} {cash_forecast} Rent · price · yield · {rent:darwin} {median:darwin} {rent_yoy:darwin} {yield:darwin} {yield_standing:darwin} {yield_rank:darwin} — add :u for units ({yield:darwin:u}). {yield_standing} writes the phrase for you: "the highest of any capital" while the region leads, otherwise "3rd highest of the 8 capitals" — so a promotional line can't quietly turn into a false claim. R90 rolling median · {r90:sydney} {r90_month} {r90_month_short} and, against a fixed anchor month, {r90_at:sydney:2020-05} {r90_diff:sydney:2020-05} {r90_pct:sydney:2020-05} {r90_years:sydney:2020-05} — {r90_years} floors the span so a "5-YEAR GROWTH" heading rolls to 6 on its own. Works in TABLE cells too. Industry mix · {ind_name:darwin:1} {ind_pct:darwin:1} (rank 1–6, paired — always use both so a reorder can't mismatch them)
