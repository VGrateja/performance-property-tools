How this is measured. Every signed-in page carries a lightweight collector (shared/pp-telemetry.js). A second counts as engaged only while the tab is visible and the person gave any input in the last 60 seconds (5 minutes during fullscreen presenting) — the same engagement model GA4 uses. Beats flush once a minute into one row per person, tool and AEST day; nothing is recorded per keystroke or per click, no content is captured, and exports, embeds and the PDF renderer are excluded at source. Internal traffic (the dev account, the test account, the PDF service account) is included by default — untick “Include internal” to see staff-only numbers. Reading this data is triple-locked to the dev role: RLS on the table, a role check inside the RPCs, and this page's own gate.
